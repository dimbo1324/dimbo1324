## About

Engineer with **5+ years** of experience bridging OT and IT in oil & gas, nuclear and thermal power. I commission control systems on operating plants and build the software around them: real-time data services, digital twins and integrations between field devices and IT systems.

I enjoy solving problems on site, working side by side with operations and maintenance, and leaving systems well documented. I use AI coding tools (Claude Code, Codex) to build faster, and I verify and test every result.

## Selected work

- **2,500+ field signals** verified during SAT/FAT on refinery units (diesel hydrotreating, atmospheric-vacuum distillation), including SIS/ESD validation with the plant in operation.
- **~25% faster** delivery of new pipeline automation projects thanks to a reusable IEC 61131-3 module library (4 → 3 weeks).
- **Digital twin of a thermal power plant:** ODE-based process model, virtual PLC with 4 cascaded PID loops, MQTT / gRPC / OPC UA, Docker.
- **In-house FBD-based DSL** that lets engineers configure control logic without writing code.
- **C++ backend test automation** for a video analytics platform: unit and automated tests, Jenkins CI, WebSocket services on Linux.
- **CFD of VVER steam generators** (ANSYS CFX), validated against PIV/LDV measurements.
- **+12% yield** on an electroplating line after automation that took an operator out of a toxic environment.
